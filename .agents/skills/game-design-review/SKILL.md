# Personal Effects Game Design Review
Start from the approved roadmap and the current playable prototype, not feature wishlists. Evaluate clarity in under a minute, 60–120-second case pacing, genuinely distinct rule interactions, spatial depth, optional meaningful possessions, user frustration, fairness, touch accessibility, and authoring cost.

Ask: Does the rule change the player's reasoning or merely restate adjacency? Is there a real compliant-vs-sentimental choice? Does the intended case have alternative legitimate outcomes, and can the player understand both? Is it worthwhile for a 10-case alpha?

Do not equate number of solutions with fun, or infer replayability from optional items alone. Mark subjective judgments as hypotheses until tested with unfamiliar players.

Output: proposal, player value, mechanical novelty, smallest implementation, risks, acceptance criteria, playtest protocol, and decision **IMPLEMENT / SIMPLIFY / DEFER / REJECT**. Human decides case order, narrative and art direction.
